## ⚙️ Installation (Local Setup)

1. **Clone the repository**
   ```bash
   git clone https://github.com/faridulhaque/The-Coffee.git
   cd The-Coffee

2. **Install dependencies**

    npm install


3. **Run the development server**

    npm run dev


4. **Open in browser**

    http://localhost:3000
